# Campus illustration

`building-e.glb` is the unmodified ready-made **building-e** model from
[Kenney's City Kit Commercial 2.1](https://kenney.nl/assets/city-kit-commercial).

- Model size: 128,208 bytes
- The original `Textures/colormap.png` (11,002 bytes) is served alongside the model.

`building-e-poster.webp` is a static render of this same model for the landing page.
No new model was generated. The scene is an illustration, not a representation
of a particular university's premises. Both files are served locally.
